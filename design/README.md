# Design decisions

The living design document is the entry point and holds every decision made so far:
<https://claude.ai/code/artifact/2a04bda1-2d30-45ad-80e5-37e55f7a8d51>

This folder holds decisions that page does not cover. One file per decision, numbered,
named `NNN-short-slug.md`, and never rewritten once merged. A decision that turns out
wrong gets a new file that supersedes it by number, so the reasoning stays readable.

Each file answers four things. What was decided. What the alternatives were. Why this
one. What would have to change for us to revisit it.
